# Deliver owner-flow QA

Open a collection’s `…` menu and choose **Deliver…**. Confirm `Esc` returns focus to the menu button, and tab switching retains a typed title and password.

## Private link

1. Choose **Private link**, set an optional password and expiry, then create the link.
2. Use **Copy** and **Open**; confirm the copied URL opens the private visitor gallery.
3. Return to Deliver and verify created/expires, view count, client-selection completion, and picks are shown.
4. Use **Revoke**, confirm the second click, and verify the tab returns to link creation.

## Client gallery

1. Choose **Client gallery**, set title, layout, theme, cover, download options, and optional password, then create it.
2. Use **Copy** and **Open**; confirm the client gallery has the selected cover and download behavior.
3. Return to Deliver and verify visit count and frozen-photo count, then update one setting.
4. Use **Revoke**, confirm the second click, and verify the tab returns to client-gallery creation.

## Website

1. Choose **Website**, set title and URL name, then publish.
2. When publishing finishes, use **Copy** and **Open**; confirm the static website gallery resolves.
3. Return to Deliver and verify the Website status row and republish action are shown.
4. Use **Unpublish**, complete the typed photo-count confirmation, and verify the status becomes unpublished.
