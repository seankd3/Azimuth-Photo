# Security policy

## Reporting a vulnerability

Please report security issues privately through [GitHub security advisories](https://github.com/Sean-Kenneth-Doherty/photo-archive/security/advisories/new). Do not open a public issue for a vulnerability.

Include a clear description, reproduction steps, affected version, and any proof of impact. We will confirm receipt, investigate, and coordinate disclosure with you.

## Supported versions

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |
