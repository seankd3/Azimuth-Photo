How To Read The New Shape

Old habit

Find the giant file, scroll, patch the nearest helper.

  • app.py owned too much backend behavior.
  • app.js owned too much browser behavior.
  • db.py and thumbnails.py mixed engines and facades.

New habit

Start with the workflow or engine boundary, then follow the README.

  • User workflows live in features/<feature>/.
  • Shared app mechanics live in core/.
  • SQL ownership lives in data/repositories/.
  • Cache/image work lives in thumbnails/.
  • Browser behavior lives in static/js/<area>/.
